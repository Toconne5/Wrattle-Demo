# Wrattle - The Social Investing App
### Turn every dollar into a conversation - and an investment.


## Local Environment Setup

- Download and install Node.js - https://nodejs.org/en/download
- Clone the Wrattle repo and follow these steps to start the service
```sh
git clone git@github.com:Toconne5/Wrattle-Demo.git
cd Wrattle-Demo
```

### WebStorm Run Configuration
- Navigate to Edit Configurations > npm
- Package: `Wrattle-Demo/package.json`
- Command: `run`
- Scripts: `dev`

### CLI Startup
Run these commands to start the service
```sh
npm i
npm run dev
```

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
